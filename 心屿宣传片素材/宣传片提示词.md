# 心屿 · AI 情感陪伴｜15 秒宣传片提示词包

> 用途：把本文件 + 同目录图片一起交给其他 AI 视频工具（可灵 / Runway / Veo / Pika / 即梦等）生成视频。
> 成片规格：15 秒 / 16:9 横屏 / 720p 以上（建议 1080p）/ 24 或 30fps。

---

## 一、成片设定

| 项目 | 设定 |
| --- | --- |
| 风格 | 温暖治愈、生活感，写实与柔和插画质感融合 |
| 色调 | 暖粉 + 暖黄，柔光、浅景深、轻微胶片颗粒 |
| 节奏 | 慢，镜头运动柔和，不用快切 |
| 声音 | 无人物对白、无旁白配音、无歌声，仅轻柔钢琴 + 轻微环境音 |
| 字幕 | 简体中文，白色细体，底部居中，带柔和阴影（建议后期叠加，见第五节） |
| 禁忌 | 画面内不生成任何文字、字幕、水印、Logo、乱码 |

## 五、字幕与后期

- **字幕文案与时间轴**
  - 00:00–00:04　有些话，只想说给懂你的人
  - 00:04–00:08　她记得你的情绪，也会先开口
  - 00:08–00:12　白天陪你，深夜也在
  - 00:12–00:15　心屿 · AI 情感陪伴（主标题）/ 有情绪，也会主动想你（副标题）
- **样式建议**：思源黑体 / 苹方 细体，1080p 下字号约 48–56px，白色，阴影 40% 黑，底部居中，距底边约 8%。
- **转场**：仅镜头 2→3 用 0.5 秒叠化（cross dissolve），其余硬切。
- **音乐**：轻柔钢琴，60–70 BPM，结尾 1 秒淡出；不加人声。
- **说明**：AI 视频模型直接生成中文字幕容易乱码，建议画面生成时不带字，字幕与品牌标题在剪辑软件（剪映 / PR / CapCut）中叠加。

## 七、给视频工具的使用建议

1. **首选图生视频**：分别上传四张分镜图作为首帧，生成 4 / 4 / 4 / 3 秒片段，再按顺序拼接；一致性最好。
2. **一次性生成**：上传 `晚晚头像` 与 `云海浮岛背景` 作为参考图，粘贴第三节整段提示词，时长设为 15 秒、比例 16:9。
3. **保持一致性**：每段都强调「黑色微卷长发、米白针织开衫、暖粉暖黄、柔光浅景深」。
4. **字幕**：按第五节在后期添加，避免模型生成乱码文字。
